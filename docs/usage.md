# 使用指南

## 分镜参数

| 字段 | 说明 |
| --- | --- |
| `id` | 小写字母、数字、连字符，最多 64 字符，用于输出命名 |
| `prompt` | H3 提示词，必填 |
| `width` / `height` | 256–2048 的 32 倍数；上限是输入校验，不表示硬件能运行 |
| `duration` | 5–15 秒，换算为 24 fps 的 `17k+5` 帧数 |
| `steps` | 4 或 8，必须安装相应 Turbo LoRA；默认 8 |
| `seed` | 可选，非负安全整数；省略则随机，并保存实际值 |
| `firstFrame` | 可选，已在 ComfyUI input 中的图片文件名 |

建议从默认 5 秒、480P 开始。把 8 步换成 4 步会改变模型效果，不能把它当作无损加速。

## 提示词与声音

示例采用三个字段：`integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。它们分别描述画面/动作、环境音、配乐。不要把对白、雨声、音乐全部混成一个笼统要求。

图生视频首行示例：

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

## 从参考视频到自己的作品

当前版本负责执行与素材交接，参考理解仍需要人工或 Agent 参与：

1. 看完整参考片，记录镜头、时长、主体、镜头运动、字幕和声音。
2. 明确保留什么结构、替换什么人物或主题。
3. 给每个需要生成的镜头写独立 brief，按顺序生成；必要时用参考图固定外观。
4. 检查输出，再把接受的片段放入 Hypit 工程组织时间线。
5. 单独补充字幕对齐、转场和版式；当前导出器不会自动生成这些内容。

用文字描述参考动作不等价于 Ref2VA。当前 `run` 命令不会把原始参考视频送进 H3。

## 路径、私有素材与部署

所有命令在仓库根目录运行。图片和输入路径应从 ComfyUI 自身管理；不在公开示例中写入电脑用户名或私人图片路径。模型目录不需要复制进本项目。

`config.local.json` 中可配置 `workflowDirectory`，以便将 GUI 工作流持久保存到 ComfyUI。未设置时仍会写到项目的 `output/<job>/workflow.json`，可以手动拖入 ComfyUI。

ComfyUI 地址可以修改，当前工具不管理认证或公网部署。默认使用本机回环地址。生成过程中不自动停止其他模型进程，也不清空用户队列。

## 恢复语义

任务提交前保存 `status: submitting`，收到回执后立即保存 `promptId`。如果进程恰好在服务接收任务后、保存回执前退出，状态可能没有 ID。这时应先检查 ComfyUI 队列/历史，找回原 ID；不要盲目重新运行。

`resume` 查询原服务中的任务历史。ComfyUI 历史被清空或服务器更换后，客户端无法凭空恢复远端记录。超时不代表服务停止计算；该命令不会调用全局 interrupt。

同一项目内每次 `run` 使用新目录。多进程同时启动仍可能抢在队列检查后各自提交，因此建议只运行一个生成命令。
